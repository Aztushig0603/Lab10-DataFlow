# Results directory

`manual-javac-check.txt` and `manual-mutation-check.txt` are real local Java compile/run sanity checks performed in the preparation environment. They are **not** Maven Surefire output and do not replace the required assignment evidence.

The following required files must be generated by running Maven 3.9+ in the student's environment:

- `mvn-verify-alldefs.txt`
- `jacoco-alldefs.csv`
- `mvn-test-M1.txt`
- `mvn-test-M2.txt`
- `mvn-test-M3.txt`
- `mvn-verify-final.txt`
- `jacoco-final.csv`

They are intentionally not fabricated because Maven was unavailable in the preparation environment.

Additional manual-only files:
- `manual-test-runner.txt`: 13 test methods run with a temporary lightweight JUnit-API-compatible stub runner (not the official JUnit engine).
- `manual-mutation-test-runner.txt`: M1/M2/M3 mutation outcomes using that same temporary runner. This is useful sanity evidence, but the assignment still requires Maven Surefire logs.
